## Git cheat sheet

If you've edited files in your local repository and you want to commit those to your remote (e.g. the files you see on GitHub's page), here's the steps to follow.

1. `git add <file>` (where `<file>` is the file you added or changed.)
2. `git commit -m "<message>"` (where `<message>` is some useful description of what you changed/added.)
3. `git push`

These should all complete without error. If you get errors.... Google is your friend, or your classmates or your professor :)
